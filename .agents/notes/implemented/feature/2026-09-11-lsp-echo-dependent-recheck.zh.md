# Agent Note: lsp-echo 连带检查改动脚本的引用者

Status: implemented

[English](2026-09-11-lsp-echo-dependent-recheck.md) | 中文

## 问题

Godot 引擎只对递给它的那个文件给出诊断,所以签名变化真正弄坏的文件从来不是被改的那一个:把 `func foo(x: int)` 改成 `func foo()`,`a.gd` 自己是干净的,代价落在调用者身上。pre-step 只检查自上一步以来 mtime 变动的文件,于是"签名变化"与"没有变化"无从区分——快照保留旧结果,错误到不了模型。

## 决策

pre-step 发现本轮有 GDScript 改动时,解析这些文件可以被怎样引用——它们的 `class_name`,以及它们的 `res://` 路径——并把被监听文件里提到其中任何一个的并入同一轮检查,候选集含 `addons/`,因为 addon 脚本也可能引用项目里的类。引用判定是声明名的词边界匹配,加上加载字符串的大小写不敏感路径字面匹配,因此 `extends StaleA`、`var a: StaleA`、`StaleA.new()`、`preload("res://a.gd")` 都算作引用,而更长的标识符 `StaleAB`、不同的文件 `res://a.gdshader` 不算。

删除或改名 GDScript 的那一轮改为复查整个项目:消失的文件读不出调用者用过的名字,而那些调用者会一直带着未知类型,直到有东西去打开它们。脚本**出现**之后调用者报 `Could not find type` 的情形,由[引擎桥 Note](2026-09-11-lsp-echo-godot-editor-bridge-rescan.zh.md)从另一侧覆盖。

引用索引每轮重建,不做缓存。在实测项目上(约 500 个 GDScript 文件)一趟 18 ms,低于维护一份与新建、删除、改名保持一致的缓存的成本。

## 考虑过的其他做法

| 否决 | 理由 |
| --- | --- |
| 脚本一变就全项目 sweep | 每轮 502 个文件。引擎支持,但为一行改动付一次全项目扫描,正是增量路径要避免的代价。 |
| 只查改动文件所在目录 | 模块化项目里引用大多跨目录——实测中被引用最广的脚本有 233 个引用者,散布在整棵树里。 |
| 让引擎给出全项目诊断 | 引擎只为客户端打开过的文件发布 `publishDiagnostics`,没有可索取的全项目诊断通道。 |
| 维护一份持久的引用图 | 重建只要 18 ms,而持久副本还要在新建、删除、改名、路径变化时失效——机器比它省下的活儿更多。 |

## 后果

被很多文件引用的脚本一改,那些文件就被拉进当轮检查。实测(约 500 个 GDScript 文件的真实项目):每个 `class_name` 脚本平均 5.4 个引用者;引用最广的 `CommonName` 有 233 个,改它就会连同这 233 个一起检查。删除或改名一个脚本,代价是那一轮多做一次全项目复查。

匹配是刻意的过近似:注释里提一句类名也算引用。过近似的代价是引擎批量处理时多一个干净文件;反向错误的代价是快照陈旧,而后者正是这条 Note 要防的。

## 测试

`lib/dependents.js` 由 20 项校验覆盖,在临时目录上跑一次(直接引用、`extends`、类型注解、`preload` 路径、带行尾注释的声明、大小写不同的路径、addon 目录里的引用者、注释提及、更长的标识符、无关文件、`.gdshader` 路径前缀、排除自身、shader 文件、无目标改动、迭代器一次性契约,以及精确集合断言)。它是用完即弃的脚本而不是随包测试:仓库的测试包含范围是 `packages/`、`apps/`、`scripts/`,不含 `plugins/`。

索引在真实项目上只读实测:约 500 个 GDScript 文件下一趟 14–27 ms,385 个 `class_name` 脚本 6.0 s 扫完,11 个脚本没有任何引用者,平均 5.4,最大 233。

引擎行为另外用真实 headless 引擎验证过:把 `a.gd` 从 `foo(x: int)` 改成 `foo()` 后,检查 `b.gd` 立刻报出 `Too many arguments for "foo()" call`,无需引擎重扫、无需等待——"先打开过依赖"与"从未打开依赖"两种情形都量过。自起的引擎会从磁盘读取改动后的依赖,所以缺失的那次检查就是全部原因;引擎可能持有自己那份编辑前副本的模式是 attach 编辑器,那由[引擎桥 Note](2026-09-11-lsp-echo-godot-editor-bridge-rescan.zh.md)覆盖。
